GitHub Pagesでの公開方法

数分で無料でWebサイトとして公開できます

  1. GitHubでリポジトリを作成:
    GitHubにログインし、「New repository」をクリック。リポジトリ名（例: propose-game）を入力して作成します。
  2. `index.html` として保存:
    このページのすべてのコードをコピーし、ファイル名を index.html にして保存します。
  3. ファイルをアップロード:
    作成したリポジトリ画面で「Uploading an existing file」を選び、index.html をドラッグ＆ドロップしてCommitします。
  4. GitHub Pagesを有効化:
    リポジトリの **Settings** ➔ **Pages** を開き、SourceのBranchを `main`（または `master`）の `/ (root)` に設定して「Save」を押します。
数分待つと https://ユーザー名.github.io/リポジトリ名/ で公開されます！
